# Agent Guidance — SME Accounting

## Non-obvious build/run commands
- **SDK pinned:** `global.json` → .NET 10.0.401, rollForward latestFeature. Use `dotnet` version 10.0.x. CI restores with `--locked-mode` (`Directory.Packages.props` central versioning).
- **Build all:** `dotnet build -c Release SmeAccounting.slnx`. All projects set `TreatWarningsAsErrors=true`, `AnalysisLevel=latest-recommended`, `EnforceCodeStyleInBuild=true`. Expect zero warnings.
- **Tests:** `dotnet test`. Individual project: `dotnet test tests/SmeAccounting.Architecture.Tests`. Filter: `dotnet test --filter "FullyQualifiedName~ArchitectureTests"`. Integration tests spin up `postgres:16.14-alpine` via Testcontainers — no local DB required.
- **EF migrations:**
  - Add: `dotnet ef migrations add {Name} --project src/SmeAccounting.Infrastructure --startup-project src/SmeAccounting.Api`
  - Apply: `dotnet ef database update --project src/SmeAccounting.Infrastructure --startup-project src/SmeAccounting.Api`
  - Script bundle: `scripts/ef-migrations.sh bundle|script`. Uses `SME_ACCT_CONNECTION_STRING` env var fallback to appsettings `DefaultConnection`.
- **Migrations are fail-fast:** `Program.cs` throws if pending migrations exist at startup. Always run update before `dotnet run`.

## Architecture and module boundaries
- Clean Architecture + Modular Monolith, single deployable.
- Layer rules enforced by `tests/SmeAccounting.Architecture.Tests/ArchitectureTests.cs`:
  - SharedKernel → nothing
  - Domain → SharedKernel only
  - Application → Domain + SharedKernel
  - Infrastructure → Application + Domain + SharedKernel
  - Api → Infrastructure + Application + Modules
  - Module Domain projects must not depend on Infrastructure.
- Module interface: `IModule` with `IServiceCollection AddModule(IServiceCollection)`. Modules registered in `src/SmeAccounting.Api/Program.cs` via `AddModules([...])`. Extension pattern `Add{Module}Module()` used.
- Each module has 3 sub-projects: `Domain/`, `Application/`, `Infrastructure/`. Modules live under `src/Modules/`. 12 MVP modules.
- Composition root: `src/SmeAccounting.Api/Program.cs` + `ModulesAddExtensions.cs`. Do not register services outside modules.

## Database and naming quirks
- PostgreSQL 16.14. Naming convention **snake_case** enforced by `SmeAccountingDbContext.ApplySnakeCaseNamingConvention()` (converter, not DB default). Tables/columns/FKs snake_case.
- Primary keys: `bigint GENERATED BY DEFAULT AS IDENTITY`. `BaseEntity.Id` is `long`. EF annotation `NpgsqlValueGenerationStrategy.IdentityByDefaultColumn`.
- Concurrency: shadow property `xmin` (type `xid`) on all `BaseEntity` subtypes. `IsConcurrencyToken=true`, `BeforeSaveBehavior.Ignore`, `AfterSaveBehavior.Ignore`. No app-managed version column.
- Global soft-delete filter for `ISoftDeletable`. Audit fields via `IAuditable` (`CreatedAtUtc`, `CreatedBy`, `UpdatedAtUtc`, `UpdatedBy`). Tenant isolation via `ICompanyScoped`.
- Decimal precision default `numeric(18,2)`. Extension `uuid-ossp` enabled.
- Seeds: `Demo Company` + `Head Office` branch via EF Core `SeedData()`. Vietnamese Circular 133 COA seeded via migration `Circular133COASeed`. Identity seeds: roles Admin/ChiefAccountant/Accountant/Viewer/Auditor, user admin@smeaccounting.vn / Admin@12345 (override via `ADMIN_PASSWORD` env var).
- Migrations must be idempotent-safe. Design-time factory reads `SME_ACCT_CONNECTION_STRING`.

## Security and Identity conventions
- ASP.NET Core Identity with cookie auth only. Password policy: 8 min, digit/lower/upper/non-alphanumeric, lockout 5 attempts/15 min, unique email, require confirmed email.
- Cookie settings: 8h expiration, sliding, HttpOnly, SameSite Lax, SecurePolicy SameAsRequest, paths `/Accounts/Login`, `/Accounts/Logout`, `/Accounts/AccessDenied`.
- RBAC: 19 permissions in `Permissions.cs`. Policy provider intercepts `Permission:*` → `PermissionRequirement`. `PermissionAuthorizationHandler` checks `permission` claims, admin bypass.
- `ClaimsPrincipalExtensions` provides `GetUserId`, `GetDisplayName`, `GetBranchId`, `GetPermissions`, `HasPermission`.
- Security headers middleware: X-Content-Type-Options nosniff, X-Frame-Options DENY, X-XSS-Protection 1; mode=block, Referrer-Policy strict-origin-when-cross-origin, CSP default-src 'self', HSTS max-age 31536000 (excludes /health).
- Data protection keys persisted to filesystem (`Security:DataProtectionPath` or `./dataprotection-keys`). For multi-instance use external store.
- ForwardedHeaders configured for Nginx reverse proxy.

## Testing quirks
- Test tiers: Domain unit, Application unit (NSubstitute), Infrastructure integration (Testcontainers Postgres), Architecture (NetArchTest), Security (permissions), Web (WebApplicationFactory).
- Infrastructure tests: `DatabaseIntegrationTests` verify snake_case naming, bigint PKs, soft-delete filter, FK constraints, seed data presence. They spin up containers automatically.
- Architecture tests enforce layer rules, controller IL size <1000, audit/soft-delete property presence.
- No global test setup; Web tests set env to `Testing` and remove DB health checks.
- Run full CI locally: `dotnet restore`, `dotnet build --no-restore`, `dotnet test --no-build --verbosity normal`.

## Style / workflow conventions
- `.editorconfig` applies. `TreatWarningsAsErrors` means fix warnings before commit.
- `LangVersion 14.0`, `Nullable enable`, `ImplicitUsings enable`.
- NoWarn: NETSDK1188, CA1000, IDE0161, CA1861, CA1848, CA1873.
- `UseArtifactsOutput=true`. Artifacts go to `artifacts/bin/.../release`.
- Central package versions in `Directory.Packages.props`. Restore locked mode in CI.
- Do not add third-party auth libraries. Cookie auth only.
- Migration policy: all migrations must be nullable-safe and idempotent. Check `Program.cs` pending migration check.

## Environment and secrets
- Connection string priority: `SME_ACCT_CONNECTION_STRING` env var > appsettings `ConnectionStrings:DefaultConnection`.
- Default dev login: admin@smeaccounting.vn / Admin@12345. Override password via `ADMIN_PASSWORD` env var at seed time.
- Data protection path configurable via `Security:DataProtectionPath` or env var.
- App listens on `http://localhost:5000` by default.

## Things to avoid
- Changing DB naming conventions — snake_case is enforced by converter.
- Using UUID PKs — project uses `bigint identity`.
- Adding new top-level services outside `AddInfrastructure` or module `AddModule`.
- Adding third-party auth providers.
- Running migrations manually in dev without fail-fast check.
