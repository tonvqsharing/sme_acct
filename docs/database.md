# Database

## Engine

- **PostgreSQL 16.14** on Alpine
- **EF Core 9.0.0** with **Npgsql 9.0.0**
- Connection string: `DefaultConnection` in appsettings, fallback to `SME_ACCT_CONNECTION_STRING` env var

## Naming Convention

All database identifiers use `snake_case`. Enforced by custom converter in `SmeAccountingDbContext.ApplySnakeCaseNamingConvention()` (`src/SmeAccounting.Infrastructure/Persistence/SmeAccountingDbContext.cs:129`).

| C# Name | DB Name |
|---------|---------|
| `Company` | `companies` |
| `Branch` | `branches` |
| `Account` | `accounts` |
| `AuditLogEntry` | `audit_log_entries` |
| `CreatedAtUtc` | `created_at_utc` |
| `CompanyId` | `company_id` |

Foreign key constraints also snake-cased: `FK_companies_branches`.

## Primary Keys

`bigint GENERATED BY DEFAULT AS IDENTITY` (PostgreSQL 10+ identity columns).

- `BaseEntity.Id` → `long` (8 bytes, sequential)
- EF Core annotation: `NpgsqlValueGenerationStrategy.IdentityByDefaultColumn`
- All FKs (`CompanyId`, `ParentId`) are `bigint`

See ADR-001: `docs/adr/001-naming-and-pk-strategy.md`.

## Concurrency Token

PostgreSQL `xmin` system column used as optimistic concurrency token for all `BaseEntity` subtypes.

- Shadow property `Xmin` (type `uint`, column `xmin`, type `xid`)
- `IsConcurrencyToken = true`, `BeforeSaveBehavior.Ignore`, `AfterSaveBehavior.Ignore`
- No application-managed version column — relies on PostgreSQL native MVCC

Implementation: `src/SmeAccounting.Infrastructure/Persistence/SmeAccountingDbContext.cs:40-50`.

## Soft Delete

`ISoftDeletable` interface (`src/SmeAccounting.SharedKernel/Primitives/ISoftDeletable.cs`):

```csharp
bool IsDeleted { get; set; }
DateTime? DeletedAtUtc { get; set; }
Guid? DeletedBy { get; set; }
```

**Global query filter** applied automatically in `SmeAccountingDbContext.OnModelCreating()` for all entities implementing `ISoftDeletable`. Filter: `IsDeleted == false`.

## Tenant Isolation

`ICompanyScoped` interface (`src/SmeAccounting.SharedKernel/Primitives/ICompanyScoped.cs`):

```csharp

```

Applied to: `Account`, `Branch`. Future: global query filters per company.

## Decimal Precision

All `decimal`/`decimal?` properties default to `numeric(18,2)` — set globally in `OnModelCreating`.

## PostgreSQL Extensions

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

Enabled via `modelBuilder.HasPostgresExtension("uuid-ossp")`.

### Commands

```bash
# Add new migration
dotnet ef migrations add {MigrationName} \
  --project src/SmeAccounting.Infrastructure \
  --startup-project src/SmeAccounting.Api

# Apply pending migrations
dotnet ef database update \
  --project src/SmeAccounting.Infrastructure \
  --startup-project src/SmeAccounting.Api

# Generate SQL script
dotnet ef migrations script \
  --project src/SmeAccounting.Infrastructure \
  --startup-project src/SmeAccounting.Api \
  --idempotent --output artifacts/sql/script.sql
```

### Migration Policy

- `Program.cs` throws `InvalidOperationException` on startup if pending migrations detected (fail-fast)
- `DesignTimeDbContextFactory` reads `SME_ACCT_CONNECTION_STRING` env var for tooling
- All migrations must be idempotent-safe
- Seeds use anonymous types to include `xmin` shadow property

## Backup

For production:

```bash
# Daily backup
pg_dump -Fc smeaccounting > backup_$(date +%Y%m%d).dump

# Restore
pg_restore -d smeaccounting backup_20260101.dump
```

Recommend `pgBackRest` or cloud-managed backups for point-in-time recovery.
